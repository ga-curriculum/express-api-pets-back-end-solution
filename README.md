# Express API - Pets Back-End - Solution

## About

This repo contains the solution code for the [Express REST API Pets](https://git.generalassemb.ly/modular-curriculum-all-courses/express-rest-api-pets) lecture.

## Getting started

Fork and clone this repository to your local machine.

After moving into the cloned directory, run `npm i` to download the dependencies.

Create a `.env` file in the root of the project:

```bash
touch .env
```

and add your MongoDB URI to it. It will look something like this, but with your username and password:

```plaintext
MONGODB_URI=mongodb+srv://<username>:<password>@sei-w0kys.azure.mongodb.net/pets?retryWrites=true
```

Start the app with `npm run dev`.
